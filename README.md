# Kinetic PTY (FitApp)

App de fitness, nutrición con IA y beneficios en comercios locales para Ciudad de Panamá.
MVP en React + Vite + Tailwind, pensado como PWA.

## Correr en local

Requiere Node.js 18 o superior.

```bash
npm install
npm run dev
```

Abre la dirección que muestra la terminal (normalmente http://localhost:5173).

## Estado actual

Prototipo navegable con datos de ejemplo: onboarding, panel del día, Nutri-Coach IA (simulado),
club de beneficios con pase QR, tarjeta para Instagram Stories y perfil con suscripción.

## Pendiente para el MVP

- Escaneo real de comida con IA (foto o texto).
- Conexión con Strava (OAuth).
- Usuarios y datos (backend, por definir).
- Cobro de la suscripción (tarjeta y Yappy).
